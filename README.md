## Introduction
The Twiddle Puzzle Solver is designed to solve challenging puzzles using various algorithms.

## Features
- Global autoplay functionality allows users to automatically solve the puzzle without manual intervention.  
- A global "Move Next" feature enables quick navigation through puzzle states.  
- The terminate feature allows users to stop the solving process at any time.  
- The GUI now contains an updated screenshot path: `img/gui.png`.
- New algorithms incorporated into the solver include **Top-Down Dynamic Programming (DP)** and **Bidirectional BFS**. These provide enhanced solving capabilities and flexibility to the users.
- The timing outputs for each solver are displayed for user reference, including MDF DP build time, helping to analyze performance across different algorithms.
